# 图标设计

应用图标和菜单栏（托盘）图标采用同一个构图：两个头像前后叠放。应用图标的前景头像右下角带一个绿色小圆点。

- **含义**：这台 Mac 上有多个 Claude Desktop 账号，当前用的是前面这一个。
- **来源**：直接借用 app 自己的视觉语言，也就是账号卡片上的渐变头像，和表示「当前使用」的绿色在线点。
- **不画箭头**：叠放本身就表达了切换；箭头在 16–32 px 下会糊成一团。
- **不加的元素**：文字、Claude 标志、Anthropic 商标元素。

两个图标都用矢量绘制。不用图像生成模型，避免锯齿、杂点和不对称。

## 应用图标

源文件：`assets/app-icon.svg`。用 `rsvg-convert` 渲染为 `assets/app-icon.png`（1024 × 1024，透明背景）。

画布 1024 × 1024，按 macOS 图标网格：

| 元素 | 规格 |
| --- | --- |
| 底板 | 圆角矩形 x=100 y=100 w=824 h=824，圆角 185。纵向渐变：顶部 `#FFFFFF`，底部 `#ECEEF4`。描边 1 px `rgba(0,0,0,0.06)`。下方阴影：y 偏移 10，模糊 20，`rgba(0,0,0,0.22)`，阴影完全落在画布内 |
| 后景头像 | 圆，中心 (424, 430)，半径 200。135° 渐变 `#FFC46B` → `#F0742E`（与界面里的橙色头像一致） |
| 前景头像 | 圆，中心 (600, 610)，半径 210。135° 渐变 `#8E9BFF` → `#4F5BEA`（与界面里的蓝色头像、PRO 徽章一致） |
| 前后分隔 | 后景头像在前景头像外 22 px 内用蒙版镂空，露出底板渐变，把两者干净地分开。不要画成固定颜色的色环：底板是渐变，色环在底部会显出一圈亮边 |
| 人像剪影 | 每个头像里一个白色剪影，不透明度 0.95：头部圆半径约为头像半径的 0.33，圆心在头像中心上方 0.24 r 处；肩部是一个椭圆（宽 1.22 r，高 0.98 r），中心在头像中心下方 0.62 r 处，被头像圆裁切。头与肩之间留出约 0.06 r 的缝 |
| 当前账号圆点 | 绿色 `#34C759` 圆，半径 58，圆心在前景头像中心右下 45° 方向、距离 0.98 r 处（约 (746, 756)）。前景头像在圆点外 18 px 内同样用蒙版镂空 |

- **整组居中**：两个头像和圆点作为一组，在底板内按视觉居中。按外接框计算后整体平移即可，大约向左上移动 (17, 24)。
- **小尺寸可读性**：缩小到 32 px 时，两个圆、前后关系和绿点都必须能分辨。如果剪影在 32 px 下糊成一团，可以适当加粗或加大，但构图不变。

## 菜单栏图标

模板图（`Template: true`）：只有黑色和透明（可带半透明），macOS 会按菜单栏配色重新着色。文件是 `desktopui/tray-icon.png`，64 × 64，由 `desktopui/tray.go` 用 `//go:embed` 内嵌，显示为约 18 pt。替换这个文件后重新构建即可；`TestTrayIconIsTransparentTemplatePNG` 会检查尺寸、是否只有黑色、角落透明、不透明像素足够多。

下表是最初的设计，仅作参考：

| 元素 | 规格 |
| --- | --- |
| 后景头像 | 空心圆环：中心 (23, 23)，半径 15，线宽 4.5 |
| 前景头像 | 实心圆：中心 (39, 39)，半径 19 |
| 人像剪影 | 从前景实心圆里镂空成透明：头部圆中心 (39, 33.5)，半径 6.5；肩部椭圆中心 (39, 53)，半径 11.5 × 9，被前景圆裁切。头与肩之间留 2 px 缝 |
| 前后分隔 | 前景圆外 3.5 px 范围内全部透明，把后景圆环切断 |

- **不画绿点**：模板图是单色的，绿点在 18 pt 下也看不出来。
- **内容范围**：整体落在 4–60 px 范围内，四周留空。
- **测试**：更新 `TestTrayIconIsTransparentTemplatePNG` 的采样点，检查以下四处：
  - 角落透明；
  - 后景圆环上有像素；
  - 前景圆实心部分有像素；
  - 剪影头部中心透明。
